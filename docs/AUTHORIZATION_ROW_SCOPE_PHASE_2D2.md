# Phase 2D-2: row-scoped first pull

Migration `0013_authorization_row_scope_PREPARED.sql` adds restrictive `engrase_sync` policies for authenticated SELECT/INSERT/UPDATE/DELETE. They intersect the existing store permission matrix, so the matrix remains the role/store grant and the new helper adds the row boundary. It adds only `LUBRICADOR/equipment.can_read=true`, required for Mi Turno/QR; the restrictive policy confines that permission to authorized locations. ADMINISTRADOR and PLANIFICADOR remain global within the matrix. SUPERVISOR and LUBRICADOR are limited to active legacy crew membership and its `locationId`; this phase does not use `crew_locations`.

The row classifier uses persisted fields already present in the client and gateways: equipment `locationId`; plan/point `equipmentId`; assignment `assignedCrewId` plus `equipmentId`; execution `operationalSnapshot` crew/location with a legacy equipment-location fallback; anomaly/skip equipment and crew links; validation-to-record links. A scoped row with no resolvable relation is denied. Equipment and linked records outside the current location are not returned. Shared reference stores remain governed by the store matrix. `push_tokens` and the legacy `users` store remain owner-only for every role; the latter is distinct from `app_profiles`, used for Auth identity, and is not the administrator's user-management source.

The authenticated bootstrap returns `rowScopeEnforced: true` only in the same transaction that installs the restrictive policies. If that transaction fails, the bit stays false. The rollback file only sets the bit false and deliberately retains restrictive policies; dropping those policies after the 0003 cutover could reopen broader store-level access.

This is prepared SQL only. It has not been applied to any Supabase environment. In particular, while the legacy anon policy from 0003 remains in place, anonymous requests remain a separate cutover risk; authenticated row policies do not remove it. Do not interpret local PGlite tests as production evidence.
