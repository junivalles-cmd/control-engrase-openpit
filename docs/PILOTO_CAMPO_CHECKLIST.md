# Checklist del Piloto — v1.0.0-rc1

Usar uno por turno observado. Marcar y anotar cualquier desviación en
`docs/PILOT_ISSUES_TEMPLATE.md`.

**Turno:** __________  **Fecha:** __________  **Lubricador:** __________
**Cuadrilla:** __________  **Ubicación:** __________

## Antes del turno

- [ ] Sesión correcta (usuario/nombre esperado)
- [ ] Cuadrilla correcta
- [ ] Ubicación correcta
- [ ] Mi Turno carga (sin pantalla en blanco ni "Cargando..." pegado)
- [ ] Badge de sincronización en verde/normal
- [ ] Cámara funciona (probar una foto de prueba)
- [ ] Push activo (notificación de prueba llega)

## Durante el turno

- [ ] Registrar un engrase completo
- [ ] Completar una tarea asignada
- [ ] Adjuntar una foto a un registro
- [ ] Registrar una anomalía
- [ ] Probar modo offline (apagar datos/WiFi un momento)
- [ ] Reconexión — confirmar que sincroniza solo al recuperar señal

## Al final del turno

- [ ] Los registros hechos durante el turno llegaron al servidor
- [ ] Sin registros duplicados
- [ ] Pendientes mostrados son correctos (nada que ya se hizo sigue como
      pendiente, nada pendiente real falta)
- [ ] Historial refleja correctamente lo registrado
- [ ] Comentarios del lubricador recogidos (aunque sean informales)
